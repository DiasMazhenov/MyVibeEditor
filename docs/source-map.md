# Контракт DOM ↔ HTML source-map

С v0.71 визуальный редактор хранит карту между opening-tag, полным диапазоном элемента в `serializedSource` и реальным DOM-узлом iframe.

- сканер учитывает кавычки в атрибутах, поэтому `>` внутри `title`/`data-*` не завершает тег;
- комментарии, raw-текст `script` и `style`, closing tags и декларации не становятся ложными узлами;
- `openingRangeFor(node)` возвращает только диапазон opening-tag, а `elementRangeFor(node)` — от opening-tag до парного closing-tag; void-элементы получают диапазон только своего тега;
- парные диапазоны строятся стеком, а неоднозначные/неполные карты не разрешают структурные операции и требуют Source-режим;
- CSS-инспектор и структурные операции сначала используют карту; старый поиск диапазона оставлен только для совместимых fallback-сценариев, где карта отсутствует;
- после каждой записи source карта строится заново, поэтому диапазоны не устаревают после изменения длины атрибута.

Минимальная проверка:

```sh
node --test tests/source-map.test.js
```
