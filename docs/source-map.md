# Контракт DOM ↔ HTML source-map

С v0.27 визуальный редактор хранит карту между opening-tag в `serializedSource` и реальным DOM-узлом iframe.

- сканер учитывает кавычки в атрибутах, поэтому `>` внутри `title`/`data-*` не завершает тег;
- комментарии, raw-текст `script` и `style`, closing tags и декларации не становятся ложными узлами;
- карта хранит диапазон opening-tag и связывает его с DOM-узлом через внутреннее свойство, не добавляя служебный атрибут в пользовательский HTML;
- CSS-инспектор и inline-SVG replacement сначала используют карту, а старый поиск диапазона остаётся fallback для DOM, который не удалось сопоставить;
- после каждой записи source карта строится заново, поэтому диапазоны не устаревают после изменения длины атрибута.

Минимальная проверка:

```sh
node --test tests/source-map.test.js
```
