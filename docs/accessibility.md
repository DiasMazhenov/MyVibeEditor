# Доступность v0.56

- Группы полей сохраняют естественную высоту и порядок, поэтому подписи и элементы управления не накладываются друг на друга.
- Один общий scrollbar охватывает весь контент CSS-инспектора, включая HTML/ARIA и footer; вложенных scroll-контейнеров нет.
- Весь CSS-инспектор имеет один вертикальный scrollbar; заголовок, выбранный узел и кнопки остаются в том же доступном потоке без вложенной прокрутки.
- CSS-инспектор не выталкивает поля за пределы viewport: группы используют адаптивную сетку и внутреннюю прокрутку только по высоте;
- при смене выделенного элемента значения полей HTML/ARIA и CSS обновляются для нового узла, сохраняя понятную связь между фокусом и инспектором;
- Контекстное меню открывает первый доступный пункт и поддерживает `ArrowUp`/`ArrowDown`, `Home`, `End`, `Enter`, `Space` и `Escape`.
- После закрытия меню фокус возвращается к элементу, с которого оно было открыто, если элемент ещё доступен.
- Design tokens имеют одного владельца в fallback-слое; theme использует палитру без дублирования.
- Кнопки preview имеют `aria-label`, нативный `title` и видимые локальные Iconify-иконки; названия доступны при наведении и через assistive technology.
- Resize-зона CSS-инспектора имеет `role="separator"`, вертикальную ориентацию, понятный `aria-label` и клавиатурное управление: `ArrowLeft`/`ArrowRight`, `Home`, `End`.
- Mobile bottom-sheet сбрасывает desktop inline-ширину и учитывает `safe-area-inset`, поэтому поля не выходят за границы узкого viewport.
- Command palette вынесена в отдельный shell-модуль: команды представлены нативными `button`, результат поиска очищается через `textContent`, а клавиатура поддерживает `Ctrl/Cmd+K`, стрелки, Enter и Escape.
- Preview-кнопки и mobile menu работают через нативные кнопки, `aria-pressed`, `aria-expanded`, `aria-hidden` и возврат фокуса после Escape.

# Доступность v0.30

Цель этапа — базовая WCAG 2.1 AA-совместимость для панели editor/auth и ключевых сценариев: вход, переключение `html/text`, открытие `Файлы`/`Настройки`, context menu и CSS-инспектор.

Сделано:

- визуальные action-иконки получили `role="button"`, `tabindex="0"` и `aria-label`;
- вкладки получили `role="tab"` и клавиатурную активацию Enter/Space;
- password visibility toggle доступен с клавиатуры и обновляет `aria-label`;
- добавлены видимые `:focus-visible`, `prefers-contrast: more` и `prefers-reduced-motion` правила;
- server-rendered file actions сохраняют role/label через DOM allowlist;
- CSS-сортировка файлового списка переведена с O(n²) поиска на `usort()`.

Проверки:

- `node --check myvibehtml.js` и PHP lint — автоматический smoke;
- `security-smoke.sh` и HTTP regression — PASS;
- ручной checklist для release: пройти Tab от auth до панели, активировать Enter/Space, проверить Escape для inspector/context menu, увеличить масштаб до 200% и проверить ширину 320px.

Полный axe/скринридер-аудит не заявляется выполненным: в проекте намеренно нет браузерной тестовой зависимости, а текущая среда не предоставляет headless browser.
