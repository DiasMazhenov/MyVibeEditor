# Changelog

## 0.85

- Служебные preview-узлы `<style>` и `<edit>` теперь явно исключаются из DOM ↔ HTML source map вместе с `<base>`; повторное открытие CSS-инспектора не делает карту неоднозначной, и live-изменения снова применяются.
- Добавлены регрессионные проверки для всех текущих preview-only узлов.

## 0.84

- CSS-инспектор исключает preview-only `<base>` из DOM ↔ HTML source map, поэтому изменения CSS снова применяются к live DOM, draft и исходнику.
- Размеры, шрифт, line-height, gap и border-radius редактируются нативными number-полями с сохранением CSS-единиц; цвета показываются в hex с нативным color picker.
- Поля инспектора и HTML-разметки выровнены в две колонки с общей широкой строкой для display и тега.

## 0.83

- CSS-инспектор применяет CSS и HTML-атрибуты по диапазону открывающего тега; структурные операции по-прежнему используют полный диапазон узла.
- scrollbar редактора, инспектора и админки оформлен в фирменной graphite/teal-схеме с нативным fallback для Chromium и Firefox.

## 0.82

- из HTML-инспектора удалены поля `role`, `aria-label` и `aria-hidden`; заголовок и пункт меню упрощены до `HTML`;
- CSS-инспектор теперь фиксирует изменения в local draft/timeline и сразу обновляет состояние кнопки `Сохранить`.

## 0.81

- возле названий HTML-файлов в Pages добавлена локальная иконка файла из Tabler/Iconify;
- иконка файла использует тот же фиксированный слот, что и папка, поэтому названия выровнены по одной вертикали.

## 0.80

- папки в разделах Pages и Files показываются локальной иконкой рядом с названием без подписи `Folder`;
- таблица Pages принимает один или несколько файлов drag-and-drop и загружает их в открытую папку с тем же CSRF-контрактом;
- отдельное поле выбора файла скрыто, а файловые действия в toolbar представлены локальными иконками Tabler/Iconify с `title` и ARIA-label.
- убраны рамки у названий папок, добавлен единый слот иконки для выравнивания папок и файлов, а подпись `HTML` возле страниц удалена.

## 0.79

- список «Страницы» админки теперь открывает папку текущего default-файла, показывает вложенные папки и HTML-файлы и позволяет перейти вверх;
- над списком добавлены Copy/Paste, Duplicate, Rename, Delete, Upload и New folder с единой CSRF-моделью файлового обозревателя;
- исправлено paste между папками: backend дублирует файл в текущую открытую папку, а не всегда рядом с источником;
- карточка авторизации центрируется по горизонтали и вертикали на desktop и mobile.

## 0.78

- добавлена отдельная кнопка админки в верхнюю панель; после нового входа из `/admin` пользователь возвращается в редактор;
- админка получила разделы «Страницы», «Медиа» и файловый обозреватель с preview, upload, новой папкой, Copy/Paste, Duplicate, Rename и Delete;
- добавлены `demo-about.html` и `demo-contact.html` для проверки списка редактируемых страниц;
- операции обозревателя защищены текущей сессией и CSRF-токеном, а удаление файлов создаёт backup.

## 0.77

- иконка Dashboard теперь переводит на страницу админки, а не открывает модальный слой поверх редактора;
